# Wapari font assets

Bundled Unicode fonts for offline rendering and PDF reports.

- Noto Nastaliq Urdu: Urdu script and Latin glyph coverage.
- Noto Sans Devanagari: Hindi script and Latin glyph coverage.
- Both fonts are distributed under the SIL Open Font License 1.1; see OFL.txt.

The Chinese (zh) interface currently relies on Android's system CJK font fallback. A complete Noto Sans SC font is substantially larger than the other fonts and is not included in this initial asset batch; Chinese PDF embedding must be added before claiming fully self-contained Chinese PDF support.
